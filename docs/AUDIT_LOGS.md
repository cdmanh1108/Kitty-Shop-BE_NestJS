# Audit log read contract

`GET /admin/audit-logs` requires `audit.view` and scopes every read to the
authenticated shop. Existing page/limit/entityType/entityId filters are retained;
the API DTO now documents all snapshot, actor, request and pagination fields.
The API mapper serializes `createdAt` explicitly as an ISO timestamp.

Rows are ordered by createdAt descending, then ID descending to make ties stable.
`actorDisplayName` is the current staff membership name, not a historical snapshot.
A single batched shop-scoped membership read resolves names for the returned page;
it never queries another shop or includes credentials/contact data. Missing/deleted
membership names remain null, and web actors are not resolved as staff.

Audit persistence, sanitization, append-only history and best-effort application
semantics remain unchanged. No migration or new write endpoint is involved.
The Admin consumes this response on `/nhat-ky-thao-tac`; API contracts are exported
and generated by the existing tools.
